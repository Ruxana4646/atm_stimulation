# 💳 ATM Simulation System | Streamlit Web App

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Streamlit](https://img.shields.io/badge/Streamlit-WebApp-red)
![Status](https://img.shields.io/badge/Status-Deployed-success)

This project is an **ATM Simulation System** built using **Python and Object-Oriented Programming (OOP)** and later deployed as an **interactive web application using Streamlit**.

The project demonstrates how core Python logic can be transformed into a user-friendly web interface, similar to real-world financial systems.

---

## 📊 Project Objective

- Simulate real ATM operations using Python
- Apply **OOP concepts** to structure financial logic
- Convert a **notebook-based program** into a **deployable web app**
- Practice **user interaction, validation, and session handling**

---

## 🚀 Features

- 🔐 PIN creation and authentication  
- 💰 Account balance management  
- ➕ Deposit and ➖ Withdraw money  
- 🔄 Change PIN functionality  
- 🌐 Interactive Streamlit UI
